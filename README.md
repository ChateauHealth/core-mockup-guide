# CORE UI Mockup: picking guide

A short scrolling presentation that shows how to clone the CORE UI Mockup, review
it with Claude, dictate what you like, and bring those picks into CORE.

Live page: https://chateauhealth.github.io/core-mockup-guide/

It is one static file, `index.html`, plus the images and loops in `assets/`.
There is no build step. Open `index.html` in a browser, or serve the folder:

```
python -m http.server 5199
```

The mockup repository itself is private. This guide holds no private data: the
screenshots show the mockup's fictional sample data only.
